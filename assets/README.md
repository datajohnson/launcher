# Icons Directory

This directory contains icon assets for the Launcher app.

## Required Icons

1. **icon.png** - Main application icon (256x256 recommended)
2. **tray-icon.png** - System tray icon (32x32 recommended)
3. **icon.ico** - Windows icon file for the built application

## Creating Icons

You can use the provided SVG files (`icon.svg` and `tray-icon.svg`) as a starting point.

### Convert SVG to PNG using online tools:
- https://cloudconvert.com/svg-to-png
- https://www.aconvert.com/image/svg-to-png/

### Create ICO file:
- https://convertio.co/png-ico/
- https://www.icoconverter.com/

## SpaceX Theme Colors

- Primary Blue: #00a8e8
- Dark Blue: #005288
- Background Black: #000000
- Dark Gray: #0a0a0a
- Border Gray: #1a1a1a

The icon should feature a rocket or arrow pointing upward, representing launch and progress.
